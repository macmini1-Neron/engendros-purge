## Model style (geometrie)
> voxel-inspired stylized low-poly hard-surface game asset. Use primitive-based geometry, boxy
> armor volumes, faceted polygon planes, flat shading, chunky proportions, simplified mechanical
> parts, low-detail tracks, angular turret, and clean readable silhouette. Do not create a realistic
> high-poly tank. Do not use smooth subdivision. Do not make it fully voxel cubes. It should be a
> normal low-poly mesh with Minecraft-like proportions and blocky stylization.

## Texture style (diffuse atlas)
> Create stylized low-poly military vehicle textures using a low-resolution hand-painted
> diffuse/albedo texture atlas. The texture style should look Minecraft-inspired / voxel-ish, with
> pixel-art decals, hard color blocks, flat painted shadows, limited military green palette, no PBR
> realism, no procedural noise, no smooth gradients, no high-res photorealistic materials. Use
> nearest-neighbor pixelated texture filtering and keep all wear, panel lines, markings, mud and
> highlights hand-painted directly into the diffuse map. T62 1972
